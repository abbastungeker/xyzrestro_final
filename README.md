# XYZ Restro

XYZ Restro is a full-stack restaurant ordering and management application developed as a university group project at the University of Technology Sydney.

The application provides a customer-facing restaurant menu and ordering process, along with management pages for products, staff, customers, and orders.

## Features

### Customer Features

- Account registration and login
- Restaurant menu browsing
- Individual product details
- Shopping cart management
- Simulated checkout
- Order submission

### Staff and Administrator Features

- Product management
- Customer listing
- Staff account management
- Order viewing
- Role-based dashboard interface

## Technologies

### Frontend

- React
- Vite
- React Router
- React Bootstrap
- Context API

### Backend

- Node.js
- Express
- SQLite

### Testing

- Jest
- React Testing Library

## Running the Project

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

## Limitations

This is a student project rather than a production-ready restaurant platform. Authentication, authorization, payment processing, and order management use simplified implementations for demonstration purposes.
